# Distribute Catalogs as committed JSON with a content-hash Manifest

Catalogs are generated by a build-time transform, committed to the repository and served as static assets alongside a Manifest. Each Catalog's version in the Manifest is a hash of its content, computed by the transform.

A hand-maintained version number is a step a human forgets; a content hash cannot be. Committing the output means the build never depends on the network or on upstream availability.

## Consequences

The Manifest carries no required/optional flag. Dropping the monsters and rules-reference datasets — around 1.5 MB with no screen to consume them — left a payload small enough that a two-tier download would have been machinery serving one Catalog, so every Catalog is required and installs together.
