# Creation asks the minimum; the Sheet edits everything

Creating a Character asks for a name, race, class and Level, and nothing else. Subclass is deliberately optional, since most classes do not choose one before Level 3. Everything else is set on the Sheet.

A creation wizard plus a fully editable Sheet is two editors for one model, and they drift. Since the Sheet must be editable during play anyway, a wizard could only ever duplicate it. Race, class and Level are the minimum that makes armor class, hit points, proficiency bonus, saves and skills all compute to something real, so the new Character is immediately a character rather than an empty form.
